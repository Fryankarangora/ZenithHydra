# ZenithHydra

Microservices-driven Smart Engine for scalable real-time processing, powered by Auto-Scaling System architecture.

With ZenithHydra, you get a lightweight tool that stays out of your way.

**What you get**

- Microservices-driven Smart Engine for scalable
- real-time processing, powered by Auto-Scaling
- System architecture

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ZenithHydra.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ZenithHydra is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
